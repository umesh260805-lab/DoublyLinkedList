# Doubly Linked List

## Data Structure
I implemented a Doubly Linked List using HTML, CSS and JavaScript.

## Operations Supported
- Insert at Beginning
- Insert at End
- Delete from Beginning
- Delete from End
- Search

## Project
This project provides a simple webpage to perform operations on a Doubly Linked List. The current list is displayed on the webpage after each operation.

## Technologies Used
- HTML
- CSS
- JavaScript
